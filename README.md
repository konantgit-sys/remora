# Remora — Nostr Engagement Agent

Автономный агент для участия в обсуждениях на Nostr. Remora слушает ленту выбранных релеев, оценивает посты сообщества и отвечает содержательными комментариями в аналитическом тоне — как участник дискуссии, а не как вещатель.

**Статус:** прототип 1.0 (открытая разработка, MIT)
**Основа:** Nostr (kind:1), LLM-прокси (Mistral), собственный адаптер релеев

---

## Почему ответы, а не посты

Обсуждение строится вокруг чужих идей. Вместо того чтобы создавать отдельный поток контента, агент добавляет ценность в существующие треды — отвечает по существу, продолжает диалоги, реагирует на реакции. Это осознанный формат участия: ценность для авторов и читателей, а не шум в ленте.

## Возможности

- **Сканирование ленты** — мониторинг kind:1 на нескольких релеях одновременно
- **Оценка перед ответом** — LLM-evaluator решает, достоин ли пост ответа; жёсткие фильтры отсекают спам, оффтоп и агрессию
- **Генерация ответов** — аналитический тон, без шаблонных фраз
- **Память диалогов** — помнит, что уже сказал, не повторяется, продолжает треды
- **Самообучение** — ответы с реакциями получают больший вес; авторы, чьи посты вовлекают, приоритизируются
- **Whitelist авторов** — управление кругом тем и авторов через конфиг
- **Экономичность** — LLM-бюджет ~$1.5/мес

## Принципы

1. Только содержательные ответы — никаких standalone-постов
2. Каждый ответ должен быть ценнее среднего комментария человека
3. Память диалогов — никаких повторений
4. Самообучение на реальных реакциях
5. Реальный бюджет — никаких дорогих экспериментов

## Быстрый старт

```bash
cp .env.example .env        # вписать nsec и релеи
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 -m src.core.remora
```
